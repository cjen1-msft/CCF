Throwaway prototype CCFRaft trace mapping

Can per-node FIFO parsing remove trace preprocessing?

This demo tests whether one globally ordered NDJSON trace can be demultiplexed into per-node FIFO queues, reduced by deterministic LR-style rules, and mapped to one ordered list of canonical Lean actions. It also tests a mid-trace mode that materializes observed node variables while leaving unavailable variables explicit.
