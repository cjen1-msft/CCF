How preprocessing changes the trace

The reducer never sees raw raft_driver output. preprocess_for_trace_validation removes the producer immediately before each add_configuration, collapses recv_propose_request_vote plus become_candidate, synthesizes bootstrap from the initial leader sequence, groups records by node, and merges them by h_ts.

The v2 certificate retains and hashes the resulting NDJSON lines. It does not retain the discarded records or a manifest that explains each transformation.

Useful strictness

Exact schema remains the right policy for the frozen golden oracle.

Conflict with the grammar-safe cuts ADR

The ADR allows reductions to consume non-contiguous global events while each node advances through local grammar. A safe cut closes every overlapping reduction interval. The fixed reducer instead assumes one complete 53-event order and cannot leave a reduction open at either edge.

Hardening roadmap

Gate each claim before widening it

Each stage ends with an acceptance test. Do not use the next claim level until its gate passes.

Stage 0

Freeze the oracle

Rename the current contract replicate-v1. Preserve exact schema, exceptions, negative controls, certificate rebuild, and canonical replay.

Gate

The current fixture and mutation suite pass byte-for-byte. No production caller imports ordinal tables.

Stage 1

Make input provenance lossless

Store the raw digest, producer hashes, event schema, timing semantics, per-node sequence, stream incarnation, and a transformation manifest.

Gate

Changing any discarded raw record changes the manifest or raw digest. The transformed fixture still rebuilds v2 semantics.

Stage 2

Build the interleaving grammar

Use per-node FIFOs, open reductions, N-to-M productions, set coverage, grammar-safe cuts, typed failure classes, and resource ceilings.

Gate

All 50 scenarios have a declared accepted, unsupported, incomplete, or invalid result. The eight same-function scenarios need no ordinal special case.

Stage 3

Prove correspondence and footprint

Independently check event-to-macrostep relations. Add a batch action or refinement lemma. Extract the footprint from raw lower bounds and canonical reads and writes.

Gate

Every accepted production has an independent correspondence result and footprint coverage witness. Bounded UNSAT is invalid only after completeness.

Stage 4

Add production instrumentation and CI

Add correlation and entry digests if review accepts them. Run the corpus manifest and grammar coverage proof in CI.

Gate

Version skew, partial capture, loss, timeouts, and ceilings return safe typed results. Coverage deltas require review.
